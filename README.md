# Creature Reserve (working title)

A browser game prototype about keeping, studying and raising creatures. This build
is the opening: build a dog enclosure at Hollin Vale, win a stray puppy's trust,
bring it home, care for it as it grows into an adult, and record it in the Life Atlas.

```
npm install
npm run dev
```
Open http://localhost:5173 (desktop browser, keyboard and mouse).

Controls: WASD move · Shift brisk walk · C calm pace · drag to look · E interact ·
F call/stay · V observe · B build · L Life Atlas · Esc menu.

Docs: [project brief](docs/PROJECT_BRIEF.md) · [asset record](docs/ASSETS.md) · [roadmap](docs/ROADMAP.md)
